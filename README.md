# Telegram Notes Bot

> Telegram bot that stores personal notes and sends timed reminders.

## Features

- Save, list and delete notes per user
- Timed reminders with the job queue
- JSON storage
- Configuration through `.env`

## Tech stack

Python 3.10+, python-telegram-bot

## Getting started

```bash
pip install -r requirements.txt
cp .env.example .env   # add your bot token
python bot.py
```
